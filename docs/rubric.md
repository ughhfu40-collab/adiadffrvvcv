# Рубрика оценки сгенерированных заданий

Каждое задание оценивается по 5 критериям: 0 — нет, 1 — да. Урок принимается, если у каждого задания 1–3 равны 1, а средний балл по 4–5 не ниже 0,5. Критерии 1–3 обязательны. Учитель исправляет нарушения в редакторе до сохранения.

| # | Критерий | Как проверяется |
|---|---|---|
| 1 | **Валидный урок**: JSON проходит общую Zod-схему, все ID предложений и `correctOptionId` существуют | автоматически (`validateLesson`, `npm run rubric`) |
| 2 | **Ровно один правильный ответ**: верный вариант следует из текста, остальные — нет (ни дословно, ни выводом) | вручную / LLM-судья |
| 3 | **Цитата подтверждает ответ**: каждый допустимый набор `evidenceSets` достаточен для ответа и не содержит лишних предложений; для `infer` — минимум два предложения | вручную / LLM-судья; длина набора — автоматически |
| 4 | **Навык соответствует типу**: `find` — факт из одного предложения; `match` — связь деталей; `infer` — вывод, которого нет в тексте дословно | вручную |
| 5 | **Язык**: грамотные формулировки на языке урока (для казахского — проверка носителем), подсказка не выдаёт ответ | вручную |

Типичные ошибки модели (из прогона `gemma3:12b`, 27.11.2026): «правильный» вариант добавляет факт, которого нет в тексте; доказательство описывает прошлое состояние вместо нынешнего; опечатки в казахских формах (`аккумулятордар`, `үзілу жиіні`); подсказка с неверным словом (`Қысқа уақытта` вместо `Қыста`).

## Результаты реального прогона (gemma3:12b, Ollama 0.40.18, MacBook arm64 16 ГБ, 27.11.2026)

Генерация через экран учителя: казахский — 234 с (черновик 1), 230 с (черновик 2), 209 с (черновик 3, на видео); русский — 189 с.

Две проверки отмечены раздельно:
- **Авто** — формат урока и ID предложений и вариантов (Zod-схема на сервере и при импорте, `npm run rubric`).
- **Человек** — правильность ответа и то, что доказательство его подтверждает (сверка с исходным текстом вручную).

| Черновик | Задание | Авто: формат и ID | Человек: ответ верен | Человек: цитата подтверждает | Итог |
|---|---|---|---|---|---|
| ru «Голос старого радио» | t1 find | ✓ | ✓ 1968 (s1) | ✓ | принят |
| ru | t2 match | ✓ | ✓ | ✓ s5+s6 | принят |
| ru | t3 infer | ✓ | ✓ | ✓ s2+s3 | принят |
| kk «Ауылдағы күн станциясы», черновик 1 | t1 find | ✓ | ✓ | ✓ s1 | принят |
| kk, черновик 1 | t2 match | ✓ | ✗ «сабақ үзілу азайды» нет в тексте | ✗ s3 — прошлое, а не изменение | **не засчитан**, переписан учителем |
| kk, черновик 1 | t3 infer | ✓ | ✓ (вывод допустим) | ~ s1 слабое, лучше s3+s4 | принят после правки |
| kk, черновик 2 | t1 find | ✓ | ✓ | ✓ s1 | принят |
| kk, черновик 2 | t2 match | ✓ | ✗ «бұл құрылысты мүмкін етті» нет в тексте | ✗ одна цитата s2 для сопоставления | **не засчитан**, переписан учителем (s3+s4) |
| kk, черновик 2 | t3 infer | ✓ | ✓ | ✓ s6+s7 | принят, исправлены формулировка и опечатка «Електр» |

| kk, черновик 3 | t3 infer | ✓ | ✓ | ✓ s6+s7 | принят |

Вывод: автоматическая проверка пропустила все три неудачных казахских t2. Формат и ID она ловит, смысл — нет. Поэтому черновик модели не попадает к ученикам сам: урок сохраняет учитель после проверки в редакторе.
