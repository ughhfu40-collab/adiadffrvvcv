## Остальные замечания
- kk-solar t3 (вывод): верный вариант утверждает «электр жарығын үнемі көреді», а в тексте этого нет (s4 говорит только о вечерних уличных фонарях). Все три варианта начинаются с этой фразы. Набор доказательств s3+s4+s6+s7 слишком широкий. **Не засчитано.**
- kk-bus t1: опечатка в неверном варианте «Отзық» (должно быть «Отыз»); в подсказке «Текстің» вместо «Мәтіннің».
- kk-bus t3: вывод «үлгерімі жақсарды» опирается на s7. Лучший набор — s5+s6+s7 (связь «ремонт → автобус не опаздывает → успеваемость»), модель дала s5+s7. Неуклюжая форма «жөнделісінен».
- ru t2: в тексте «после первых выпусков», а не «из-за». Причинность — допустимый вывод. Второй допустимый набор s5+s6 учитель может добавить вкладкой «Набор 2».

## Вывод
Новое правило качества (по одному заданию каждого типа, минимум два разных предложения у сопоставления и вывода) выполнено во всех трёх черновиках. Но два ID в наборе не гарантируют, что ответ действительно требует обоих предложений (kk-solar t2), и не ловят искажение слова в ответе (kk-bus t2). Казахские задания по-прежнему нужно проверять учителю. Русский черновик пригоден после мелких правок.
