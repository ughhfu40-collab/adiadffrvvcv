# Математика: реальная генерация gemma3:12b (ветка feat/oqy-math, 27.11.2026)

Запрос шёл через `/api/generate` с `subject: "math"`, ответы сохранены рядом (`ru-cinema.json`, `kk-garden.json`). Результат до правки учителем:

| Ситуация | Время | Структура и ID | Проверка расчёта кодом | Ручная сверка |
|---|---|---|---|---|
| ru «Поход в кино», 8 кл. | 218 с | ✓ | **t2 поймана:** в варианте 21 600 ₸, по формуле со скидкой 19 440 ₸. **t3 поймана:** «по расчёту верный вариант — c» | t1 ✓; t2 ✗ (сама модель пишет «ошибка в вариантах»); t3 ✗ (бессмысленные варианты про попкорн) |
| kk «Мектеп бағы», 7 кл. | 177 с | ✓ | **t2 поймана:** модель посчитала 4 × 3 600 + 1 000 = 10 200, по формуле 15 400 ₸ | t1 ✓; t2 ✗; t3 ✗ — формально сходится, но вопрос и варианты бессмысленны (код не ловит) |

Первая попытка заняла больше 300 с (модель загружалась): клиент на Node обрывает ожидание заголовков через 300 с. Браузер и сервер (лимит 600 с) такого ограничения не имеют.

**Вывод:** у Gemma 12B на этих задачах арифметические ошибки в 3 из 6 заданий. Проверка кодом поймала все три ошибки в числе или выборе и не дала сохранить урок. Смысл задачи (kk t3) по-прежнему проверяет учитель.
